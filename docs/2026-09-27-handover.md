## Gotchas learned this session

- PipeWire Rust `Listener` unregisters on drop — store it.
- `Node` is not `Clone`; hold the `RefCell` borrow for the call.
- The `spa` re-exported by `pipewire` 0.10.1 is **libspa** (frame-based
  `Builder` + `Pod::from_bytes`), NOT `pipewire-native-spa`.
- `SPA_Props_params` = `0x80000`; control names are `<node>:<port>`
  (e.g. `band_l_0_filter:Freq`), resolved by filter-graph `find_port`.
- Filter **type** is topology (biquad `label`), not a live control.
- `pkill -f target/debug/mini-eq` matches the launching shell — kill by
  `pgrep -x mini-eq` instead.
