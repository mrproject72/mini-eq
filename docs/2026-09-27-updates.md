## Fixed this session

1. **UI → backend pipeline connected** (`main.rs`, `window.rs`).
   `launch_gui` starts the filter-chain engine against the detected default
   physical sink and shares the backend with the window via
   `Rc<RefCell<Option<PipeWireBackend>>>`. The window's 33 ms update loop
   pushes band + preamp state (debounced 400 ms) to the engine.

2. **Live `SPA_PARAM_Props` control** (`pipewire_backend.rs::apply_live_controls`).
   Mirrors upstream `set_node_params`. A persistent registry listener captures
   the live `mini_eq_sink` `Node` proxy; edits build a `SPA_PARAM_Props` object
   whose `params` property (`SPA_Props_params` = `0x80000`) is a struct of
   alternating `(control-name, f64)` pairs (e.g. `band_l_0_filter:Freq`),
   pushed via `node.set_param()`. DSP updates in ms; graph/links survive.
   - The registry `Listener` is now **stored in the backend** — listeners
     unregister themselves when dropped, so the previous `let _ =` pattern
     silently stopped receiving events.

3. **Double-free in `unload_filter_chain_module`** (`pipewire_backend.rs`).
   `take()` + `pw_impl_module_destroy` + `ModuleHandle::drop` destroyed the
   same `pw_impl_module` twice → crash on the first band update. Fixed with
   `std::mem::forget` after destroying the raw pointer.

4. **Active bands default to Bell** (`window_layout.rs::build_band_faders`).
   Every fader was created with `FilterType::Off`. The window reads fader state
   and pushes it, so all pushed bands were Off → wet/dry mix 0 → biquad
   bypassed → dragging the fader changed gain on a bypassed filter (silent).
   Active bands (`i < DEFAULT_ACTIVE_BANDS`) now default to Bell, matching
   `core::default_bands()` and upstream. Inactive bands stay Off.

5. **Filter-type change now restarts the engine** (`pipewire_backend.rs`).
   Native biquad labels are graph **topology**, fixed at module-load time
   (`label = bq_peaking`), so they are not mutable live controls. The backend
   now tracks `engine_band_types` (the types the loaded module was built with);
   a type/preset mismatch triggers unload + reload (with the stale node proxy
   cleared so the registry listener re-captures the new node). Ordinary
   Freq/Q/Gain/mute/solo edits stay live. Mirrors upstream
   `set_filter_controls` / `_engine_band_types`.

6. **Graph overlay reflects the selected band** (`window.rs`).
   The update loop passed a hardcoded `FilterType::Bell` (and fixed 1000 Hz /
   Q 1.0) to `EqGraph::update`, so switching filter types never changed the
   drawn curve. It now passes the selected fader's actual frequency/Q/type.

7. **Sidebar no longer auto-collapses** (`window.rs`).
   The Rust-invented 1320sp narrow breakpoint called `set_collapsed(true)` on
   every layout re-evaluation (a click re-triggers it), making the right panel
   vanish. Removed the forced collapse; kept only the layout compaction.

8. **Real link-factory routing** (`routing.rs`).
   `create_link` was a memory-only stub. Ported real `link-factory`
   `create_object::<Link>` via `link_nodes()`, added roundtrip-pumped
   `find_node_id_by_name()` and `list_playback_streams()`
   (`media.class = Stream/Output/Audio`); `auto_route_to_sink()` now links
   actual app playback streams into the virtual sink.
